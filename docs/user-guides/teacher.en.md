# Teacher guide (English)

**Milestone 1 status: the teaching tools are not built yet.** This guide says what you can do today and what is coming, so you do not look for buttons that are not there.

## What you can do today
- Use Tracepad in class exactly like a learner: Lesson 1, run code, Stop, offline use.
- Ask the administrator for the **teacher invite code**, create an account, open **Account** and enter the code under "Become a teacher". A wrong code is refused (five tries per ten minutes).
- Learners without email can use a username; you do not need to collect addresses.

## What is not there yet (Milestone 3)
Creating classes, join codes, assignments and due dates, and the class progress dashboard. The database already has the tables and the security rules for them (a teacher will be able to read, never change, the progress of students in their own classes), but there is no screen for them yet, so do not promise them to your class.

## Things to keep in mind
- Learner results are reported by their browsers and are not verified. Use them for practice and feedback, not high-stakes grading.
- Under-13 learners cannot create accounts themselves. The administrator can create their accounts (see the administrator guide); arrange consent with parents or the school.
- Persian lesson text is not translated yet (Milestone 4); the interface is.
