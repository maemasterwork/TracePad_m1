# راهنمای مدیر (فارسی)

راه‌اندازی کامل در [../deployment.md](../deployment.md) است (انگلیسی). این صفحه فهرست کوتاه کارهای مدیر است.

**یک‌بار راه‌اندازی**: پروژهٔ Supabase بسازید، مایگریشن‌ها را اجرا کنید، کد دعوت معلم را بگذارید، ایمیل (SMTP اختصاصی) و نشانی سایت را تنظیم کنید، سایت را با سرآیندهای لازم بسازید و میزبانی کنید و فهرست «اولین اجرا» را انجام دهید.

**معلم‌ها**: کد دعوت را به آن‌ها بدهید (محرمانه نگه دارید و هر وقت لازم شد با یک دستور SQL عوضش کنید). آن‌ها در «حساب کاربری» معلم می‌شوند. بدون کد هیچ‌کس از راه برنامه معلم یا مدیر نمی‌شود؛ نقش‌های `platform_admin` و `content_editor` فقط با اجرای SQL به‌عنوان مالک پایگاه داده داده می‌شوند:
`update public.profiles set role = 'platform_admin' where id = (select id from auth.users where email = '...');`

**زبان‌آموزان بدون ایمیل**: با `username@<VITE_USERNAME_DOMAIN>` وارد می‌شوند. اگر گذرواژه را فراموش کردند، در Supabase بخش *Authentication → Users* بازنشانی کنید. برای حذف یک زبان‌آموز، کاربر را همان‌جا حذف کنید (پیشرفتش هم پاک می‌شود).

**حساب برای زیر ۱۳ سال**: خودشان ثبت‌نام نمی‌کنند. در Supabase بخش *Authentication → Users → Add user* نشانی `username@<VITE_USERNAME_DOMAIN>` را بگذارید، گذرواژه بدهید، تأیید خودکار را بزنید و در user metadata این را بنویسید: `{"full_name": "...", "username": "...", "age_band": "under13"}`. (در محیط ساخت امتحان نشده؛ اول با یک حساب امتحان کنید.) روش کلاس‌محور در مرحلهٔ ۳ می‌آید.

**درخواست‌های حریم خصوصی**: زبان‌آموزان در «حساب کاربری» داده‌هایشان را دانلود یا حذف می‌کنند. نقش‌های پلتفرم خودشان را حذف نمی‌کنند؛ دستی حذف کنید.

**پرچم‌های ویژگی و گزارش ممیزی**: `feature_flags` (روشن و خاموش کردن ویژگی‌ها، بنر تعمیر) و `audit_log` (حذف حساب، تغییر نقش و پرچم) فقط برای مدیران پلتفرم و فعلاً با SQL در دسترس‌اند؛ صفحهٔ مدیریت در مرحله‌ای بعد می‌آید.

**افزودن درس**: کار محتواست؛ README را ببینید. `npm run content:build` را اجرا و دوباره منتشر کنید.

**پشتیبان‌گیری و پایش**: پشتیبان‌گیری Supabase را روشن کنید و بازیابی را امتحان کنید. هنوز پایش خطا نداریم (برای مرحلهٔ سخت‌سازی برنامه‌ریزی شده است).
